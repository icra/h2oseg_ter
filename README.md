# H2OSEG Ter

[![DOI](https://zenodo.org/badge/996690695.svg)](https://doi.org/10.5281/zenodo.22828047)

H2OSEG Ter is an interactive decision-support and exploratory modelling tool for the Ter River basin (Catalonia, Spain).

The application allows users to explore alternative water-management scenarios and their effects on water availability and river flows across the basin. It combines a simplified monthly hydrological model with an interactive web interface designed to support stakeholder discussion and scenario comparison.

The repository contains the source code of the web application, hydrological modelling routines, calibration scripts, and input data required to run the tool.

## Online application

The application is available at:

https://h2oseg-ter.icradev.cat

The documentation is available at:

https://icra.github.io/h2oseg_ter/

## Repository structure

- `R/` – hydrological modelling and data-processing scripts
- `calibration/` – model calibration routines
- `js/` – web application logic
- `css/` – application styles
- `assets/` – static resources
- `data_raw/` – input data
- `docs/` – additional documentation and outputs
